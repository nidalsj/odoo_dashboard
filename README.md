# 🚀 Odoo 18 Advanced Business Dashboard

A modern interactive dashboard built for Odoo 18 providing real-time business insights through KPI cards, drill-down analytics, and interactive charts.

---

## ✨ Features

### 📊 KPI Cards

- Total Sales
- Total Purchases
- Customers
- Sales Today

**Features:**
- Clickable cards
- Detailed drill-down views
- Real-time calculations
- Dynamic filtering

---

### 📈 Interactive Charts

#### Delivery Status Analysis

Users can click chart bars to open related records.

#### Monthly Sales Report

Monthly sales trends with drill-down actions.

---
